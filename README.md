# 🏠 House Price Prediction System

A Machine Learning web application that predicts house prices based on various property features using the Random Forest Regression algorithm. The project includes data preprocessing, feature engineering, model training, and a Streamlit-based interactive user interface.

---

## 📌 Project Overview

The House Price Prediction System is designed to estimate house prices using historical housing data. It applies Machine Learning techniques to analyze property attributes and generate accurate price predictions.

This project demonstrates the complete Machine Learning workflow, including:

- Data Collection
- Data Cleaning
- Data Preprocessing
- Feature Engineering
- Model Training
- Model Evaluation
- Web Application Deployment

---

## 🚀 Features

- Predict house prices instantly
- Interactive Streamlit web application
- Data preprocessing and cleaning
- Feature engineering

- User-friendly interface

## ▶️ Installation

### Clone the Repository

```bash
git clone https://github.com/shikhagupta0026/House_Price_Prediction.git
```

Move to the project folder

```bash
cd House_Price_Prediction
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the Streamlit application

```bash
streamlit run app.py
```
